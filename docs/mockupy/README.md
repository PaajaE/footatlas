# Mockupy

Klíčové obrazovky MVP (390×844): karta života, domů, výprava s mapou, zastávka, kronika, konec etapy, objevovat.

- Zdroj pravdy jsou soubory v této složce. Ukázkový obsah (texty zastávek, fakta, čísla) není ověřený.
- `canvas.json` je rozložení plátna, každá obrazovka je jeden soubor `*.dc.html`.
- Soubory se otevírají v Claude Design plátně (artifact „FootAtlas mockupy“). Pomocný soubor `support.js`, na který se odkazují, dodává editor a do repa se neukládá.
- Změny se dělají úpravou souborů zde a nahráním zpět na plátno. Verzuje se přes git.
